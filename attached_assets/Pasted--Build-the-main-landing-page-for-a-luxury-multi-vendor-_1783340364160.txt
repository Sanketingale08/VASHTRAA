## UI Design Requirement (Highest Priority)

The UI must closely match the attached reference UI inspiration images. Design the complete website UI based on the attached UI inspiration images. Treat the attached reference images as the primary design source of truth.

Homepage Requirements

The homepage must first let the user choose between two sections:

1. Explore Paithani Sarees
2. Explore Designer Sarees

Present this choice as a visually striking split-screen or two-card selector, with premium royal Indian styling (rich color palette — think deep maroon, gold, ivory — elegant typography, smooth hover/entry animations).
