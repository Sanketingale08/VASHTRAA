# Implement a Separate Super Admin Panel for TWIRLDRAPE

Develop a completely **independent Super Admin Panel** for the TWIRLDRAPE marketplace.

The Super Admin Panel should **not** be connected to the Seller Panel UI. It should be developed as a separate administration portal with its own authentication, layout, dashboard, routing, and modules.

The only connection between the main marketplace and the Admin Panel should be through the dedicated login route:

**`/admin/login`**

After successful authentication, the admin should be redirected to the **Super Admin Dashboard**.

---

# Architecture

Create three independent portals that share the same backend and database:

1. Customer Portal
2. Seller Portal (`/seller/login`)
3. Super Admin Portal (`/admin/login`)

Each portal should have its own:

* Authentication
* Layout
* Navigation
* Dashboard
* Permissions
* Routes
* UI Components

The Customer Portal, Seller Portal, and Super Admin Panel should remain independent while sharing the same backend and database.

---

Display the following summary widgets:

* Total Platform Revenue
* Total Orders
* Total Products
* Total Customers
* Total Vendors
* Active Vendors
* Active Customers
* Total Shipped Products
* Total Returned Products
* Total Refund Amount

Display these metrics using modern cards, charts, graphs, and analytics.

# Additional Requirements

* Build the Super Admin Panel as a completely separate application layout.
* The Admin Panel should only be accessible through **`/admin/login`**.
* Do not reuse the Seller Dashboard UI for the Admin Panel.
* Design a unique, enterprise-grade Admin Dashboard similar to Shopify Admin, Amazon Seller Central Admin, or Flipkart Marketplace Admin.
* Use role-based authentication so only Super Admin users can access this portal.
* Ensure the Customer Portal, Seller Portal, and Super Admin Panel remain independent while sharing the same backend database.
* Display real-time analytics, charts, reports, and marketplace statistics.
* Make the Admin Panel fully responsive across desktop, tablet, and mobile devices.
* Preserve all existing functionality. The implementation must not affect the Customer Portal, Seller Portal, routing, APIs, database connections, or existing business logic.
