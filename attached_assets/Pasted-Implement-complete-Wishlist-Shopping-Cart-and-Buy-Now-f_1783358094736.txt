Implement complete **Wishlist**, **Shopping Cart**, and **Buy Now** functionality for both the **Paithani Sarees** and **Designer Sarees** sections.

## Wishlist

Implement the following Wishlist features:

* Add to Wishlist
* Remove from Wishlist
* Move to Cart
* Save for Later
* Recently Viewed Products
* View Wishlist with all saved products
* Wishlist item count in the header
* Persistent Wishlist (items remain after logout/login)

## Shopping Cart

Implement a fully functional Shopping Cart with the following features:

* Add Products to Cart
* Update Product Quantity
* Remove Products from Cart
* Save Items for Later
* Move Saved Items back to Cart
* Apply Coupon Codes
* Display Product Price
* Display Discount
* Display Shipping Charges
* Display Taxes (if applicable)
* Display Cart Subtotal
* Display Grand Total
* Show Estimated Delivery Date
* Continue Shopping
* Proceed to Checkout

Ensure the cart updates all prices and totals automatically whenever products are added, removed, or quantities are changed.

## Buy Now Flow

Implement a complete **Buy Now** flow.

When a user clicks the **Buy Now** button on the Product Details Page:

1. Skip the shopping cart and proceed directly to Checkout.
2. Load only the selected product into the checkout process.
3. Allow the user to:

   * Select or add a shipping address.
   * Choose a delivery method.
   * Select a payment method.
   * Review the order summary.
   * Apply coupon codes (optional).
   * Place the order successfully.
4. After a successful order, redirect the user to an Order Confirmation page with the order details.

## General Requirements

* All Wishlist, Cart, and Buy Now functionality must work correctly for both the **Paithani Sarees** and **Designer Sarees** sections.
* Ensure all actions update the UI instantly without requiring a page refresh.
* Prevent duplicate products from being added to the Wishlist.
* Validate stock availability before adding items to the cart or placing an order.
* Ensure all calculations (subtotal, discounts, shipping charges, taxes, and grand total) are accurate.
* The entire experience should be responsive, smooth, and optimized for both desktop and mobile devices.
