1. SELLER REACTIVATION WELCOME POPUP
==================================================

Popup:

Title:
Welcome Back!

Message:
"Your seller account has been reactivated successfully. Welcome back! You can now continue managing your store."

Requirements:

- Show the popup only when the seller was previously deactivated and has been reactivated by Super Admin.
- Show it immediately after the seller logs in successfully.
- Display it only ONCE for that reactivation event.
- Do not show it on every subsequent login.
- Do not show it for newly approved sellers.
- Do not show it for sellers who were never deactivated.
- After the popup has been displayed, mark the reactivation welcome notification as handled.
- If the seller logs in again after the popup has already been displayed, do not show it again.

Use a reliable database/server-side state rather than only localStorage/sessionStorage so the one-time behavior works consistently across devices and sessions.

Do not modify the existing seller authentication, approval, or password logic.

2. VENDOR ID GENERATION
==================================================

Automatically generate a unique Vendor ID when a seller account is APPROVED.

Example format:

TDV000001
TDV000002
TDV000003
TDV000004

Requirements:

- Vendor ID must be unique.
- Vendor ID must never change after creation.
- Vendor ID must be permanently stored in the database.
- Vendor ID must not be regenerated during login.
- Vendor ID must not change when seller information is edited.
- Vendor ID must not change when seller is deactivated.
- Vendor ID must not change when seller is reactivated.
- Vendor ID must not be reused.
- Deleted/inactive sellers must not release their Vendor ID for reuse.
- Generate the ID automatically when the seller is approved.
- Continue the sequence automatically for every new approved seller.
- Use a scalable format that supports a large number of sellers.

Preferred format:

TDV + 6-digit sequential number

Example:

TDV000001
TDV000002
TDV000003

If the sequence reaches 999999, extend the numeric portion safely without breaking existing Vendor IDs.
