Implement strict access control so that every seller can access only their own account and data.
Requirements
 A seller can log in only to their own seller account.
 Sellers must not be able to view or access another seller's:
o Dashboard
o Shop Profile
o Products
o Orders
o Customers
o Inventory
o Analytics
o Settlements
o Support Tickets
o Earnings
o Reports
 Secure all APIs and database queries to return data only for the authenticated seller.
 Prevent unauthorized access through direct URLs, API requests, or browser
manipulation.
 Validate permissions on both the frontend and backend.
