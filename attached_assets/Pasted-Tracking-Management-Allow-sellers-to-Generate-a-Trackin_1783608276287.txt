Tracking Management

Allow sellers to:

Generate a Tracking Number
Add or Edit Tracking Numbers
Assign Courier Partners
Update Shipment Progress
View Shipment Tracking History
Monitor Delivery Status
View Courier Status
Shipping Documents

Allow sellers to:

Generate Shipping Labels
Print Shipping Labels
Generate Packing Slips
Print Packing Slips
Generate Invoices (PDF)
Print Invoices

All generated documents should be downloadable and printable.

Delivery Reports

Provide detailed shipping reports, including:

Total Shipments
Delivered Orders
Pending Deliveries
In Transit Orders
Returned Shipments
Failed Deliveries
Delivery Performance Reports

Support search, filtering, sorting, and date-range filters for all shipping reports.

Real-Time Synchronization

All shipment updates made by the seller must automatically synchronize in real time with:

Customer Portal
Super Admin Panel

The following updates should be reflected immediately:

Shipment Created
Tracking Number Generated
Courier Assigned
Shipment Picked Up
Shipment In Transit
Out for Delivery
Delivered
Return Initiated
Return Completed
Refund Processed

Customers should be able to track their orders in real time, while the Super Admin should be able to monitor all shipment activities across the marketplace.

Seller Permissions

Each seller should only be able to:

View shipments for their own orders.
Generate shipping labels for their own orders.
Update shipment status for their own orders.
Print invoices and packing slips for their own orders.
Manage returns and return pickups for their own customers.

A seller must not be able to access or modify shipment information belonging to another seller.

Additional Requirements
Build the Shipping Management module with a premium, modern, and fully responsive UI.
Display shipment statuses using color-coded badges, progress indicators, and timelines.
Include advanced search, filtering, sorting, and pagination.
Ensure all shipping operations are protected by role-based access control.
Preserve all existing functionality and ensure this implementation does not affect any existing routing, APIs, database relationships, or business logic.
Ensure seamless integration with the Customer Portal and Super Admin Panel while maintaining real-time synchronization.
